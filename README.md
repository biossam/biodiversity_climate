# 생물 다양성과 기후변화

Play2Change! 나도 환경 건축가 — 5~6학년 6차시 프로젝트 수업 사이트 (학생 + 선생님)

수업 출처: LEGO-JA PLAY2CHANGE 「생물 다양성과 기후변화」 교수학습과정안·활동지

## 화면

| 파일 | 내용 |
|---|---|
| `index.html` | 첫 화면 — 6차시 길잡이, 수업 흐름, 내 배지 |
| `lesson.html?l=1~6` | 차시 화면 — 배우기(마음 열기·영상·핵심 단어·알아보아요·만들기) · 활동지(웹 입력·스케치·인쇄) · 퀴즈 · 선생님(목표·흐름·평가) · 🖥 수업 모드 |
| `words.html` | 개념 사전 (뜻 가리고 맞히기, 찾기) |
| `play.html` | 놀이터 — 서식지 지키기 · 지구 온도 조절기 · 꿀벌 수분 놀이 · 거북 알 모래 온도 |
| `pledge.html` | 실천 다짐 — 약속 3개, 일주일 기록, 다짐 카드 PNG |
| `s.html` | **학생 전용 입구** — 이 기기를 학생 모드로 기억하고 첫 화면(`s.html?l=차시`면 그 차시)으로 보냄. 학생 모드에선 선생님 메뉴·선생님 탭·수업 모드가 숨겨짐. 풀 때는 아무 주소 끝에 `?teacher=1` |
| `qr.html` | 학생 접속 QR (첫 화면 / 1~6차시 고르기, 주소 복사, 크게 보기) |
| `teacher.html` | 선생님 — 6차시 표, 성취기준, 유의점, 설문 링크, 사이트 사용법 |

- 내용은 `data/lessons.js` 한 곳에서 고칩니다. 차시 영상은 `assets/video/차시.mp4`(720p로 줄임, 표지 `차시.jpg`)이며 `videoFile`로 연결합니다.
- 학생이 쓴 내용·배지·다짐은 그 기기 브라우저(localStorage)에만 저장됩니다.
- 차시 영상은 © The LEGO Group 저작물입니다(선생님 결정으로 수업용 게시). 원본 수업 PPT는 올리지 않았습니다. 동물 배지·놀이·퀴즈는 새로 만든 것입니다.
- 사전·사후 설문(Microsoft Forms)은 지도안에 있던 링크입니다. 학생 화면 1차시 처음·6차시 끝에 버튼이 있고, 응답은 설문을 만든 사람의 Forms 계정에 모입니다. 바꾸려면 `data/lessons.js`의 `surveys` 주소를 고칩니다.
