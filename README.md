# 생물 다양성과 기후변화

Play2Change! 나도 환경 건축가 — 5~6학년 6차시 프로젝트 수업 사이트 (학생 + 선생님)

수업 출처: LEGO-JA PLAY2CHANGE 「생물 다양성과 기후변화」 교수학습과정안·활동지

## 화면

| 파일 | 내용 |
|---|---|
| `index.html` | 첫 화면 — 6차시 길잡이, 수업 흐름, 내 배지 |
| `lesson.html?l=1~6` | 차시 화면 — 배우기(마음 열기·영상·핵심 단어·알아보아요·만들기) · 활동지(웹 입력·스케치·인쇄) · 퀴즈 · 선생님(목표·흐름·평가) · 🖥 수업 모드 |
| `words.html` | 개념 사전 (뜻 가리고 맞히기, 찾기) |
| `play.html` | 놀이터 — 서식지 지키기 · 지구 온도 조절기 · 꿀벌 수분 놀이 · 거북 알 모래 온도 |
| `pledge.html` | 실천 다짐 — 약속 3개, 일주일 기록, 다짐 카드 PNG |
| `teacher.html` | 선생님 — 6차시 표, 성취기준, 유의점, 설문 링크, 사이트 사용법 |

- 내용은 `data/lessons.js` 한 곳에서 고칩니다. 차시에 `videoUrl`(유튜브 embed 주소)을 넣으면 영상이 바로 나옵니다. 비워 두면 **영상 파일 열기**로 선생님 컴퓨터의 파일을 재생합니다(업로드 없음).
- 학생이 쓴 내용·배지·다짐은 그 기기 브라우저(localStorage)에만 저장됩니다.
